# JudgeForge Backend

FastAPI + SQLAlchemy + SQLite backend for the DOGFOOD submission and judging portal.

## Run locally

```powershell
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m scripts.seed
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

`app.main` also auto-creates the SQLite schema and runs the idempotent seed path when `AUTO_CREATE_DB=true` and `SEED_ON_START=true`.

Swagger: `http://127.0.0.1:8000/docs`
Health: `http://127.0.0.1:8000/health`

## Routes used by the frontend

Authentication: `/api/auth/login`, `/api/auth/register`, `/api/auth/me`, `/api/auth/logout`

Events: `/api/events` and track/prize detail routes

Teams: `/api/teams`, `/api/teams/my`, `/api/teams/{id}/invites`, `/api/teams/join`

Projects: `/api/projects`, `/api/projects/mine`, `/api/projects/{id}`, `/api/projects/{id}/submit`

Judges: `/api/judges`, `/api/judges/invitations`, `/api/judges/assign`, `/api/judges/assignments`

Judging: `/api/rubrics`, `/api/rubrics/active`, `/api/judge/scores`, `/api/judge/progress`

Results: `/api/results?event_id=...`, `/api/results/{project_id}?event_id=...`, `/api/export.csv?event_id=...`
